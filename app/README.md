# SINYORA GEE — Mobile App (`app/`)

This directory houses the dedicated mobile application for **SINYORA GEE (Luxury Facial, Cosmetics & Spa)**.

## Shared Backend Architecture
Both the **Web Platform (`frontend/`)** and the **Mobile App (`app/`)** connect to the exact same **Backend API (`backend/`)** and database:
- **Live Sync:** Any booking or product order placed on the Website or Mobile App appears in real time on the Admin Dashboard across both platforms.
- **Unified Catalog:** Any product uploaded (photo, price, stock, benefits) or service price updated by **GHARIBA ABDURAHMAN** or **AIM'FIZ AHMED** updates the Website and Mobile App simultaneously.
- **Push Notifications & Mobile Convenience:** Students at Royal Hostel (or requesting Domicile Service) can book treatments in 2 taps from their phone home screen, while Admins can confirm slots and manage stock on the go.
